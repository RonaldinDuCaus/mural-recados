# Bilhetim — Mural de recados

O **Bilhetim** é uma aplicação web para compartilhar mensagens, avisos e lembretes. Inspirado nos murais de cortiça com bilhetes de papel, o projeto oferece um espaço coletivo em que pequenas mensagens ajudam a organizar a comunicação de um grupo.

## Ideia do projeto

A proposta é levar o mural físico para o ambiente digital, preservando a sensação de escrever um bilhete e deixá-lo à vista. As contas cadastradas compartilham o mesmo mural: todos os usuários autenticados podem ler as mensagens, mas somente o autor pode editar ou excluir seus próprios recados.

## Funcionalidades

- Cadastro e login com e-mail e senha.
- Criação, leitura, edição e exclusão de recados.
- Título e mensagem para cada bilhete.
- Categorias de recado, aviso e lembrete.
- Escolha entre quatro cores de papel.
- Busca por título, mensagem ou autor e filtros por categoria.
- Atualização do mural em tempo real entre as contas.
- Interface adaptada para computadores e celulares.

## Identidade visual

O Bilhetim utiliza fundo de cortiça, papéis coloridos, tachinhas e ilustrações. Tons de creme e vinho, combinados com títulos em fonte serifada, dão ao site uma aparência de papelaria e diferenciam os bilhetes do restante da interface.

## Tecnologias utilizadas

- **HTML:** estrutura das telas e dos formulários.
- **CSS:** composição do mural e layout responsivo.
- **JavaScript:** interações, busca, filtros e gerenciamento dos recados.
- **Firebase Authentication:** autenticação dos participantes.
- **Cloud Firestore:** armazenamento e sincronização das mensagens, com regras que restringem alterações ao autor.

## Objetivo acadêmico

Aplicar os conceitos de desenvolvimento web em uma experiência compartilhada, integrando HTML, CSS e JavaScript puros ao Firebase para autenticação e operações de criar, ler, atualizar e excluir dados (CRUD).
